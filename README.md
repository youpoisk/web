# YouPoisk — интерфейсы сайта и Chrome-расширения

React + TypeScript + Vite. Русский интерактивный макет на демонстрационных данных. Backend и настоящая аутентификация пока не подключены. Данные сохраняются только в текущем браузере; не вводите настоящие пароли.

## Запуск

Для воспроизводимых сборок и native TypeScript-тестов используйте Node.js 24.22.3 и pnpm 11.25.0 — эти версии закреплены в CI.

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

`pnpm-workspace.yaml` разрешает установочный скрипт esbuild для сборщика Vite. Результат сборки — `dist/`, включая `dist/extension/`. Относительный base и hash-навигация подготовлены для GitHub Pages; публикация в x262e ещё не настроена.

## Карта страниц

- `#/` — обзор, поиск по демокаталогу, категории, сортировка.
- `#/library` — библиотека.
- `#/watchlist` — «Посмотрю позже», в том числе пустое состояние.
- `#/ratings` — оценки видео и каналов.
- `#/video/aqz-KE-bpKQ` — карточка видео, оценка, отзыв, отправка другу и публикация в ленту.
- `#/channel/Наука%20рядом` — карточка канала, оценка и отзывы.
- `#/friends` — друзья, входящие/исходящие заявки.
- `#/subscriptions` — подписки и подписчики (иллюстративные списки).
- `#/feed` — рекомендации, фильтры аудитории, личные отправки.
- `#/profile` и `#/user/0` — свой и иллюстративный чужой профиль.
- `#/settings` — профиль, приватность, безопасность.
- `#/notifications` — уведомления.
- `#/login`, `#/register`, `#/forgot-password`, `#/reset-password`, `#/verify-email` — макеты аутентификации и восстановления.
- `#/extension` — обзор всех интерфейсов расширения.
- Неизвестный маршрут — страница 404.

Оценки, отзывы, настройки, дружба, заявки, подписки, личные отправки и публикации изменяются локально. Это прототип сценариев, не реализация серверных политик доступа. Данные чужих профилей иллюстративные. Сводный рейтинг видео использует 100 условных голосов и текущую оценку; production-агрегаты появятся в API. Превью созданы средствами CSS, названия иллюстративные; ссылки ведут на тестовые видео YouTube.
