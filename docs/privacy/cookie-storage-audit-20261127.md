# Cookie/storage аудит — 27.11.2026

Scope: исходники сайта и API YouPoisk, оператор/сервер в России по решению заказчика. Это анализ текущей реализации, не заключение об исполнении всех требований законодательства. Иностранные режимы не признаются применимыми автоматически только из-за доступности сайта из другой страны.

## Фактические технологии
- API устанавливает только собственную cookie авторизации: production __Host-yp_refresh, development yp_refresh_dev, HttpOnly, срок до7суток; источник backend internal/transport/business/api.go credentials. Она нужна для запрошенного входа и восстановления сессии.
- localStorage сайта: несекретная область/эпоха текущего аккаунта для разделения вкладок и выбранные настройки рекомендаций. sessionStorage: временный протокол входа PKCE/состояния перехода. Это также браузерное хранение, хотя не cookies. Access token в памяти, refresh в HttpOnly cookie API; отдельного аналитического ID не добавляли.
- В src/index entry не найдено Google Analytics, Яндекс.Метрики, рекламных пикселей или иных счётчиков. Google Fonts и i.ytimg.com получают сетевые запросы; отсутствие аналитических скриптов не означает отсутствия любых внешних запросов. Cookies, которые может использовать сам хостинг, не являются управляемыми приложением и требуют проверки на реальном production-домене перед выпуском.

## Вывод для текущей конфигурации
В проверенных нормах РФ нет отдельного безусловного требования именно к всплывающему cookie-баннеру. 152-ФЗ ст.18.1 ч.2 требует доступную опубликованную политику обработки ПДн; основание обработки оценивается по ст.6, а согласие по ст.9, когда оно необходимо. Связанные с аккаунтом идентификаторы нельзя считать неперсональными только из-за отсутствия имени в cookie. Техническая необходимость не является самостоятельным всеобщим исключением из152-ФЗ: основание должно быть отражено в политике/условиях сервиса.

Для текущих необходимых авторизации/настроек не добавлен формальный баннер «Согласен» или принудительный consent wall: не выявлено обязательного требования к такому интерфейсу. Пользователь поручил добавлять уведомление при необходимости; создание ложного согласия не заменит раскрытие в политике. Общая выпускная задача YP-095/086 по утверждению и публикации политики остаётся открытой. В ней нужно раскрыть cookie/браузерное хранение, цели, сроки, оператора и ограничения отключения.

В применимых европейских режимах ePrivacy2002/58/EC ст.5(3) и национальные законы требуют предварительного согласия для необязательного хранения/доступа; строго необходимая для явно запрошенной услуги технология имеет исключение. UK: аналогичные правила PECR, регулятор ICO. Это не требование Mozilla/Google установить баннер на каждый сайт и не всеобщее требование GDPR само по себе. Если появятся аналитика/реклама/новые внешние скрипты или изменится целевой рынок, оценить необходимость полноценного выбора до загрузки этих технологий; простая кнопка «Понятно» не является согласием.
