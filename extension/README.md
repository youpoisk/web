# YouPoisk для Chrome — локальная версия 0.3

## Установка

1. Откройте chrome://extensions и включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение», выберите эту папку extension.
3. Обновите уже открытые вкладки YouTube. Закрепите YouPoisk в панели Chrome.
4. Откройте обычное видео на https://www.youtube.com/watch?v=... . В #menu рядом с лайком/дизлайком появятся «Оценить», «Рекомендовать» и «Посмотрю позже». Нажмите иконку расширения для popup.

При обновлении файлов нажмите «Обновить» у расширения и перезагрузите вкладки YouTube.

## Что работает

- Определение видео и канала по текущей странице YouTube, безопасная каноническая ссылка, preview по video ID.
- Оценка видео 1–10, изменение и удаление; оценки каналов отдельно (если страница раскрывает /@handle или /channel/UC...).
- Добавление видео в библиотеку и «Посмотрю позже», удаление из списка без потери оценки.
- Общие данные popup и панели YouTube, обновления между открытыми вкладками, сохранение при закрытии браузера.
- Popup: текущее видео, список на потом, библиотека, открытие сохранённого видео на YouTube и редактирование его оценки.
- SPA-переходы YouTube: удаление устаревшей панели и ожидание метаданных следующего видео. Shorts не поддерживаются.
- Настройки панели, показа оценки канала и адреса сайта; изменения применяются к открытым страницам.
- Ошибки отсутствия видео/метаданных, повторной загрузки вкладки после установки и отказа storage.

## Границы версии

Это рабочая локальная версия, без Go API. Логин/пароль, bearer-сессия, синхронизация с сайтом, друзья и отправка рекомендаций ещё не подключены. Фиктивная авторизация удалена. Данные принадлежат локальному браузерному профилю, не аккаунту. Индивидуальные оценки и общие рейтинги после подключения сервера будут подчиняться утверждённым политикам; сейчас общий рейтинг не вычисляется.

Сайт пока использует свои демонстрационные данные. Оценки не передаются в YouTube. Наличие /watch не позволяет без API надёжно определить, является ли ролик Short; интерфейс /shorts исключён. Превью может быть недоступно — сохраняются название и ссылка.

Предыдущие ключи макета yp-demo/yp-video-* остаются нетронутыми; в библиотеку v1 они не импортируются. Удаление расширения или очистка его storage удалит локальную библиотеку. Пока нет экспорта/облачной резервной копии.

## Безопасность и разрешения

storage — библиотека и настройки; activeTab — адрес вкладки после открытия popup. Content scripts работают только на www.youtube.com; нет доступа к cookies, всем сайтам, истории или внешнего обмена сообщениями. Service worker проверяет отправителя и video ID, валидирует значения и последовательно выполняет изменения. Прямой доступ content scripts к storage закрыт через TRUSTED_CONTEXTS. На странице нет токенов. Никаких вызовов YouTube Data API или обязательного API-ключа.

Метаданные считываются из DOM, а не считаются доверенными: ID и URL нормализуются, пользовательский текст выводится через textContent. На сервере потребуется повторная валидация и проверка условий YouTube до production-выпуска.

## Проверка

Из корня репозитория: pnpm test:extension и pnpm build. Автотесты проверяют диапазон оценок, сохранение связанного состояния, валидацию URL, границы доступа, конкурентные записи и восстановление после ошибки storage.

Для браузерного просмотра без установки: extension/demo.html (панель), extension/popup.html (кнопка примера видна только вне расширения), extension/options.html. Эти страницы используют одну локальную preview-библиотеку. В Chrome используется chrome.storage.local через service worker.

Перед публикацией нужна ручная проверка установленного расширения в настоящем Chrome: обычные видео разных каналов, переходы вперёд/назад, /shorts, несколько вкладок, закрытие/повторное открытие браузера. Предпросмотр не заменяет такую проверку.

## Версия 0.3

Компактные кнопки встроены в меню YouTube рядом с лайком/дизлайком. Выбор 1–10 открывается в popover; поддерживаются тёмная тема и перенос строки. Кнопка «Рекомендовать» сохраняет локальную отметку и не отправляет сообщения друзьям: API ещё нет. Проверена установка распакованного расширения в Google Chrome и запись оценки на реальной странице видео.


Кнопка оценки синхронизирует ширину и высоту с ytSmartImationsContent / блоком лайка-дизлайка, а семейство, размер, насыщенность и высоту строки — с нативным текстом. Размер отслеживается ResizeObserver. Проверена перезагрузка установленной версии в Chrome.
