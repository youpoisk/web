# YouPoisk для Firefox и Chrome — 0.5.1

## Возможности и аккаунт

Войдите в popup своим логином и паролем YouPoisk. Расширение создаёт отдельную сессию: аккаунт YouTube и вход на сайте не определяют автора оценок. Автор — пользователь, показанный в popup. Оценки 1–10, рецензии и «Посмотрю позже» записываются в Go API; общий рейтинг приходит с сервера. Демо-библиотеки и автоматической отправки сообщений нет. Поддерживается обычный /watch, интерфейс Shorts исключён.

Access token хранится в памяти фонового процесса, rotating refresh — в закрытом хранилище расширения. Страница YouTube не получает токены. IndexedDB хранит очередь, подтверждения и кеш собственных данных по аккаунтам. После потери связи очередь повторяет тот же ключ операции; конфликт с изменением на сайте требует явного решения. Частично загруженный snapshot не становится активным. Неизвестные данные общего рейтинга не подменяются нулём.

Старую локальную библиотеку можно явно импортировать из настроек после просмотра результата сравнения. По умолчанию сохраняются серверные значения. Журнал импорта локален данному профилю; исходная библиотека не удаляется. Выход с очередью предлагает синхронизировать, оставить или удалить ожидающие изменения. Оставленная очередь требует явного возобновления после повторного входа.

## Сборка и установка

Из корня репозитория:

```
node scripts/build-firefox-extension.mjs
node scripts/build-chrome-extension.mjs
```

Каждый запуск создаёт отдельную чистую папку `.artifacts/<browser>-extension/<uuid>` и соседний `.sha256.json`. Состав и хеши файлов при одинаковых исходниках и параметрах совпадают. Исходные библиотеки пользователей сборщик не читает и не изменяет. В пакет не входят тесты, QA-учётные данные или планы. Не устанавливайте саму исходную папку extension.

Firefox: about:debugging → «Этот Firefox» → «Загрузить временное дополнение» → manifest.json из чистой сборки. Временная установка исчезает после перезапуска браузера. Для изолированного теста используйте web-ext с новым временным профилем; не меняйте настройки проверки подписей. Постоянная обычная установка потребует подписанного Mozilla пакета.

Chrome: chrome://extensions → режим разработчика → «Загрузить распакованное расширение» → папка чистой Chrome-сборки. После обновления нажмите перезагрузку расширения и обновите вкладки YouTube. Смена Firefox dev origin требует регистрации точного moz-extension origin на API; не разрешайте произвольные extension origins.

Dev адреса зашиты: сайт http://127.0.0.1:5173/, API http://127.0.0.1:18080. Пользователь не может менять их в настройках. Production требует обоих явных HTTPS origins:

```
node scripts/build-firefox-extension.mjs --production --site-origin=https://SITE --api-origin=https://API
```

Для Chrome аналогично через build-chrome-extension.mjs. Адреса SITE/API — placeholders команды, не готовая конфигурация. Реальные production-адреса ещё не предоставлены; публикации нет. Firefox production имеет отдельный стабильный GUID, dev ID остаётся youpoisk-dev@local.invalid. Подготовленные пакеты не подписаны.

## Данные, разрешения и откат

activeTab позволяет popup прочитать текущий адрес, alarms восстанавливает очередь. Content script работает только на www.youtube.com. Доступ к API ограничен origin сборки. Нет cookies, history, all_urls или внешних сообщений. Chrome storage используется только доверенным контекстом; Firefox использует приватный IndexedDB без storage permission. Перед публикацией нужны проверка актуальных правил магазина и декларация передачи данных: учётные данные, взаимодействия с видео, названия и текст рецензий передаются API.

Завершить сессию можно выходом в расширении или отзывом соответствующей сессии в настройках сайта. Удаление дополнения или очистка его данных стирает refresh, локальную очередь, кеш и журнал импорта; уже принятые сервером оценки и рецензии остаются на сервере. Очистка данных не заменяет отзыв сессии. Не восстанавливайте старую локальную версию поверх серверной: она не понимает новые аккаунты и очередь. Перед откатом синхронизируйте изменения и отзовите сессию; новая схема не должна интерпретироваться как старая библиотека.

## Проверки и границы

`pnpm test:extension:coverage` проверяет auth/sync/очередь с требованием 100% строк и функций (это не 100% ветвей). `node scripts/extension-verify.mjs --api` последовательно выполняет контрактные проверки, сборку, Mozilla lint, реальные API smoke, Firefox IndexedDB/DOM и восстановление после потери ACK. QA изменяет только изолированные сборки; их нельзя распространять.

Автоматизированный Firefox smoke пройден. Установленный Chrome и ручной визуальный smoke на настоящем YouTube остаются отдельными выпускными проверками; контролируемый DOM их не заменяет. Хэштеги описания и local-only channel score реализованы: перенос оценки канала требует authoritative server proof и явного сравнения. Production-публикация не выполнена. Подготовка чистых ZIP: `node scripts/prepare-extension-release.mjs`; политика данных, Store listing и внешние gates находятся в extension/docs. Архивы детерминированы по байтам, не подписаны и не загружаются в магазин.
