# Политика данных расширения YouPoisk — проект

Эта версия относится к подготовленным пакетам; публичный адрес политики и реквизиты оператора ещё не заданы. Документ требует заполнения перед публикацией.

## Какие данные используются

Для входа расширение передаёт логин и пароль непосредственно настроенному сборкой API YouPoisk по HTTPS в production. Пароль не сохраняется расширением. Access token остаётся в памяти фонового процесса, rotating refresh — в закрытом хранилище расширения. Аккаунт сайта и аккаунт YouTube не используются как неявный выбор автора.

По вашим действиям передаются YouTube ID текущего видео, наблюдаемое название, хэштеги описания, оценка, отметки списка и текст рецензии. Полное описание, комментарии, боковые рекомендации и история посещений не отправляются как список интересов. Общие рейтинги и собственные данные запрашиваются у API. Превью текущего/сохранённого видео загружаются по каноническому YouTube ID с i.ytimg.com: этот сервер получает обычный сетевой запрос изображения и IP-адрес, но не токены YouPoisk. Локальная оценка канала без подтверждения сервером остаётся в браузере; перенос на сервер требует отдельного выбора.

Рецензии и оценки доступны другим пользователям согласно серверным настройкам приватности аккаунта. Расширение не отправляет личные сообщения автоматически. Данные не передаются в YouTube как его собственные лайки или отзывы. Продажа данных, рекламные трекеры и сторонняя аналитика в пакете отсутствуют.

## Локальное хранение и удаление

Кеш, очередь ещё не подтверждённых изменений, receipts, старые исходные данные импорта и его журнал хранятся в профиле браузера раздельно по аккаунтам. Гостевые оценки каналов имеют отдельную область. Кеш страниц ограничен, но исходные архивы и журнал не следует считать временным кешем. Срок действия offline lease — до семи суток; истечение требует сверки, не выдаёт разрешение повторить неизвестное изменение.

Выход предлагает отправить, сохранить или удалить ожидающую очередь. Удаление очереди не отменяет уже принятые сервером изменения. Удаление дополнения/его storage удаляет локальные данные, но не серверные оценки и рецензии. Отозвать сессию можно из настроек аккаунта на сайте; очистка storage не заменяет отзыв. Серверные данные удаляются средствами аккаунта и подчиняются опубликованной политике сервиса, которую необходимо согласовать до Store подачи.

## Разрешения и контроль

Content script ограничен www.youtube.com и проверяет текущее watch-видео. activeTab нужен для текущего контекста popup, alarms — для восстановления очереди. Chrome использует storage только из доверенных контекстов; Firefox использует приватный IndexedDB. Токены не передаются странице. Произвольный API URL в настройках не доступен. Пользователь может отключить панель в настройках или отключить расширение средствами браузера.

Firefox declarations: authenticationInfo (вход/сессия), browsingActivity (ID видео, к которому пользователь применяет действие), websiteContent (наблюдаемые метаданные видео), personalCommunications (написанная рецензия). Перед подачей проверить соответствие актуальным определениям Mozilla и Chrome Web Store; эта декларация не подтверждает одобрение магазина.
