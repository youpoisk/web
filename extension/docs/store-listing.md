# YouPoisk — описание для магазина

Статус: черновик для проверки, не опубликован. Production сайт/API, публичная ссылка политики и данные издателя ещё не предоставлены. Не подавать dev-пакет с loopback origins в магазин.

Краткое описание: Оценки, рецензии и «Посмотрю позже» для YouTube в вашем аккаунте YouPoisk.

Сохраняйте собственные оценки видео от 1 до 10, пишите и редактируйте рецензии, ведите список «Посмотрю позже». Данные отправляются в YouPoisk от имени аккаунта, в который вы вошли внутри расширения. Вход на YouTube не выбирает этот аккаунт. Доступ к YouTube cookies и Google паролям не нужен.

Общий рейтинг приходит с сервера. Изменения при временном отсутствии связи остаются в очереди с явным статусом. Конфликт с сайтом требует вашего выбора. Старую локальную библиотеку можно импортировать после просмотра сравнения; автоматической публикации старых отметок нет.

Хэштеги берутся только из описания текущего обычного видео при вашем действии. Локальная оценка неподтверждённого канала не влияет на общий рейтинг: перенос требует подтверждения канала сервером и отдельного согласия. Интерфейс Shorts не поддерживается.

Разрешения: activeTab для текущей вкладки при открытии popup; alarms для восстановления очереди; storage только в Chrome для закрытых настроек/сессии. Скрипты работают на www.youtube.com, запросы — только к API origin сборки. Нет доступа к полной истории посещений, cookies или всем сайтам. Подробности в privacy.md.

Материалы перед подачей: актуальные screenshots Firefox/Chrome на настоящем YouTube без личных данных, иконки из assets/icons, контакт поддержки, юридическое имя издателя, production ссылки и опубликованная политика. Не использовать QA screenshots как доказательство готового Store релиза.
